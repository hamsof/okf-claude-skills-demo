Checkout

checkout(items, n) turns a list of { sku, qty } into an Invoice:

  1. each item is resolved to a Product via findProduct (see catalog.md)
  2. line value = price * qty
  3. invoice total = sum of line values
  4. invoice number = INV-<n>
sequenceDiagram
    participant Caller
    participant CO as checkout
    participant Cat as findProduct

    Caller->>CO: checkout(items, n)
    loop each cart line
        CO->>Cat: findProduct(sku)
        alt known SKU
            Cat-->>CO: Product
            CO->>CO: line = price x qty, add to total
        else unknown SKU
            Cat-->>CO: throw
        end
    end
    CO-->>Caller: Invoice INV-n

interface Invoice { number: string; items: { product: Product; qty: number }[]; total: number; }

The Invoice shape is the contract every report reads — change it and you change the reports.
